# Contributing

## Branches

`main` is the stable branch.

Use feature branches such as:

- `feature/teacher-timetable`
- `feature/director-search`
- `feature/availability`
- `feature/import-parser`

## Workflow

1. Create a focused feature branch from `main`.
2. Implement the feature end-to-end where practical: database, API, UI, and tests.
3. Run tests and local validation.
4. Open a pull request.
5. Teammate reviews the change.
6. Merge only after the review and checks pass.

## Commits

Prefer small, descriptive commits using prefixes such as `feat:`, `fix:`, `docs:`, `test:`, and `chore:`.

## Source of truth

The repository code, contracts in `docs/`, and passing tests are the project source of truth. Generated snippets outside the repository do not count as integrated work.
